Nano is a programming language built around one idea: code should be as readable as plain English while still compiling down to efficient native machine code. If you know Python, you already know most of Nano — the syntax borrows heavily from it, and most simple Python scripts translate directly. The compiler takes your `.n` source files and emits NASM-ready x86-64 assembly that assembles into standalone Windows executables.

## What makes Nano different

<CardGroup cols={2}>
  <Card title="Python-Like Syntax" icon="python">
    Familiar `if/elif/else`, `while`, `for`, `def`, and `import` keywords with minimal syntactic noise.
  </Card>
  <Card title="Compiles to Native Code" icon="microchip">
    Each `.n` file produces a `.nasm` file that assembles directly to a 64-bit Windows PE executable — no runtime, no VM.
  </Card>
  <Card title="Strong Type System" icon="shield-check">
    Four scalar types (`num`, `str`, `lstr`, `list`) enforced at compile time, with automatic size limits and type-mismatch errors.
  </Card>
  <Card title="Scoped Temporaries" icon="clock">
    `tvar` variables live only for the duration of the current function or script, keeping the symbol table clean automatically.
  </Card>
  <Card title="Built-in Filesystem API" icon="folder">
    `fs.*` functions for creating, reading, writing, moving, securing, and inspecting files and directories — no external libraries needed.
  </Card>
  <Card title="Direct Memory Access" icon="memory">
    `mem.*` functions let you read, write, copy, and clear arbitrary memory addresses for low-level programming.
  </Card>
</CardGroup>

## Get started in three steps

<Steps>
  <Step title="Build the compiler">
    Assemble `nlang_main.nasm` with NASM and link it against `kernel32.lib` to produce `nlang.exe`. See [Building the Compiler](/building-the-compiler) for the full command.
  </Step>
  <Step title="Write a Nano script">
    Create a `.n` file and start writing. Variables, control flow, and functions all follow Python conventions — see the [Language Reference](/language/variables) to get comfortable quickly.
  </Step>
  <Step title="Compile and run">
    Run `nlang.exe yourscript.n` to produce `yourscript.nasm`, then assemble with NASM and link to get a native executable. The [Quickstart](/quickstart) walks through a complete example end-to-end.
  </Step>
</Steps>
