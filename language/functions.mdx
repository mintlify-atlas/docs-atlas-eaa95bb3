Functions let you group a sequence of statements under a name so the code can be organised into reusable, named blocks. In Nano, functions are declared with the `def` keyword and accept any number of named arguments. Function bodies are indented, matching Nano's Python-inspired style.

## Syntax

```text
def <name> (<args>):
```

- `<name>` — the identifier for the function. Must start with a letter or underscore.
- `<args>` — a comma-separated list of parameter names. Omit the contents for a zero-argument function, but the parentheses are always required.

```text
def greet ():
    var str msg = 'hello'

def add (a, b):
    var num result = a
```

## Function Bodies

Everything indented beneath the `def` line belongs to the function body. Like the rest of Nano, each statement occupies its own line.

```text
def clamp (val, lo, hi):
    var num result = val
    # clamp logic would go here
```

## tvar Cleanup Inside Functions

Variables declared with `tvar` are *temporary*: they exist only for the lifetime of the current function or script. When a function body ends, the compiler calls `purge_tvars`, which removes every `tvar` entry from the variable table and compacts the remaining variables. This prevents temporary working values from leaking out of a function and ensures they do not consume table space after the function completes.

```text
def compute (x):
    tvar num scratch = x   # lives only inside compute
    var num out = scratch   # out is a permanent variable

# scratch is gone here; out is still accessible
```

<Note>
  Function code generation (`def`, statement type 10) is still in progress. The compiler currently emits a `; TODO: statement type 10` placeholder when it encounters a `def` statement. The parsing infrastructure — keyword recognition, argument lists, and `tvar` cleanup — is in place, but compiled output for function bodies will be available in a future release. Do not rely on `def` producing executable code in the current version.
</Note>

## Declaring a Function

```text
def greet ():
    var str msg = 'hello'
```

The `def` keyword is followed by the function name, a parenthesised argument list (which may be empty), and a colon. Every indented statement beneath it forms the body.

## Arguments

Arguments are named in the parentheses. The compiler parses the argument list and registers the names for use inside the body.

```text
def scale (value, factor):
    var num result = value
```

## Example

```text
def add (a, b):
    var num result = a
    # b would be added to result here
```

The compiler records the `def` statement and its argument names. Full code generation — including the emitted call sequence and return mechanism — will be implemented alongside scope handling in a forthcoming release.
