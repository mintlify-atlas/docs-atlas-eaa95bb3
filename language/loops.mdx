Nano provides three loop constructs that cover the most common iteration patterns: `while` repeats as long as a condition remains true, `until` repeats until a condition becomes true, and `for` counts a variable up to a target value. All loop bodies are written with Python-style indentation — no braces or `end` keywords needed.

---

## `while` — repeat while a condition is true

The `while` loop evaluates its condition before each iteration. The body runs as long as the comparison holds.

```text
while <operand> <op> <operand>:
    # body
```

### Example

```text
var num count = 0

while count < 10:
    # body executes while count is less than 10
```

Use `while` when you need to keep looping as long as some condition is still satisfied — the classic "keep going until something breaks" pattern.

---

## `until` — repeat until a condition becomes true

`until` is the logical inverse of `while`. The body runs as long as the condition is **not** met, and stops as soon as it becomes true.

```text
until <operand> <op> <operand>:
    # body
```

### Example

```text
var num count = 0

until count == 10:
    # body executes until count equals 10
```

`until` often reads more naturally than a negated `while` when you are waiting for a specific target state to be reached.

---

## `for` — count a variable to a value

The `for` loop increments a variable on each iteration and stops once the variable equals the target value.

```text
for <var> = <value>:
    # body
```

### Example

```text
var num i = 0

for i = 10:
    # body executes, incrementing i each time, until i equals 10
```

`for` is the most concise choice when you know in advance exactly how many iterations you need.

---

<Tip>
Declare loop counters with `tvar` instead of `var` so they are automatically removed from the variable table when the current scope ends. This keeps your variable table clean and makes it clear that the counter is not needed outside the loop.

```text
tvar num i = 0

for i = 100:
    # body
```
</Tip>
